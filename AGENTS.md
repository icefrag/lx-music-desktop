# lx-music-desktop

## Agent skills

### Issue tracker

Issues 与 specs 以本地 markdown 文件形式存于 `.scratch/<feature>/`。See `docs/agents/issue-tracker.md`.

### Triage labels

五个分诊角色沿用默认标签字符串（needs-triage / needs-info / ready-for-agent / ready-for-human / wontfix）。See `docs/agents/triage-labels.md`.

### Domain docs

单上下文布局：根 `CONTEXT.md` 词汇表 + `docs/adr/` 决策记录。See `docs/agents/domain.md`.
